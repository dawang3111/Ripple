# RACER source snapshot

Contains the current RACER source, evaluation tools, tests, launch/configuration files,
and static runtime assets (maps and visualization models).

Experiment logs/results, demo media, compiled artifacts, caches and original Git history
are excluded. Upstream attribution and source copyright notices are retained.
This is a source snapshot, not an anonymized submission.

See README.md and tools/latency_eval/README.md for build and evaluation usage.
Historical defaults may refer to local racer_eval_results paths. Frozen experiment
rules and baseline_reference.json are external inputs and are not bundled here.
Supply the appropriate explicit inputs when reproducing experiments.
