# Physical UAV Validation

This directory provides annotated photographs from the controlled indoor UAV experiments supporting Ripple's case studies. The images document physical UAV validation, rather than RViz or Python simulation views.

## Image groups

- `case1-1.png`–`case1-4.png`: EGO-Planner-v2 emergency-stop case.
- `case2-1.png`–`case2-3.png`: RACER exploration case.
- `case3-1.png`–`case3-4.png`: Adaptive Swarm formation case.

Within each group, numeric suffixes give the presentation order. UAV letters are local identifiers used to explain the cases. Arrows, labels, highlighted regions, and other overlays illustrate the case narrative; they are not raw telemetry or calibrated measurements.

The files preserve the supplied image pixels and annotations. Ancillary image metadata has been removed for anonymous review. No precise location, device identifiers, network configuration, or operator information is provided. Experimental procedures and outcome criteria are described in the paper.
